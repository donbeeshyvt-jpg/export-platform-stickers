# YouTube 會員自訂表情
- 用途：頻道會員在直播聊天室或留言中使用。Super Stickers 是另外的付費功能。
- 格式：官方建議 JPEG、PNG、GIF；GIF 只顯示靜圖。使用透明 PNG 並挑出單獨可讀的代表格。
- 解析度：正方形 48×48 是官方最佳值，最高 480×480。每張 <1 MB。一般顯示約 24×24，高像素密度裝置可到 48×48 或以上。
- 裁切：48px 版本檢查輪廓、主要姿勢和留白；需要精修時以平台別 source 指定。先看 24px 原大，再看整數倍放大。
- 命名及數量：系列名稱 3～10 字元；每款 3～10 個英數字元、系列內唯一。配額隨會員數改變，按官方配額表與後台可用欄位核對。
- 上傳：YouTube Studio → 會員 → 徽章和表情符號 → 編輯；按配額選圖、輸入名稱並儲存。交付 PNG 檔案供後台使用。
- 官方依據：[圖檔、命名與配額](https://support.google.com/youtube/answer/7544492?hl=zh-Hant) · [Super Stickers](https://support.google.com/youtube/answer/7288782)。
