# Discord 伺服器素材
## 自訂表情（Emoji，小表情）
- 解析度：建議 128×128。靜態用透明 PNG；動態用 GIF。支援中心亦列 JPEG、WebP，官方部落格另列 AVIF。
- 容量：將每檔控制在 256 KB 以下；工具採十進位小於 256,000 bytes。
- 裁切及輸出：依可見輪廓等比置入方形。GIF 的多格共用色盤、保留透明索引，檢查殘影及單輪速度。
- 命名及上傳：名稱至少 2 字元，用英數或底線。伺服器設定 → Emoji → 上傳。確認權限、可用欄位與圖片縮小後的辨識度。
## 自訂貼圖（Sticker，大貼圖）
- 解析度與大小：固定 320×320，上限 512 KB，動圖最多 60 FPS。桌面聊天室約顯示 160×160 邏輯單位。
- 格式：靜態 PNG，動態 APNG 或 GIF。工具優先用 APNG 保留半透明邊緣，採十進位小於 512,000 bytes。
- 權限與名額：檢查伺服器的建立／管理表達式權限。預設與加成 1～3 級，大貼圖總欄位分別為 5、15、30、60。
- 上傳：伺服器設定 → Stickers，選擇檔案、填名稱、對應 Unicode 表情及選填的替代說明。交付圖片及資料清單。
