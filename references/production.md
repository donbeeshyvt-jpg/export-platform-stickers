# 透明母稿、裁切與動畫合成
- **母稿**：保存完整解析度的來源、圖層及 可設定尺寸的 RGBA（色彩加透明通道）工作版。高於工作畫布的直式交件另留足高來源。每個目標各從母稿縮一次。透明棋盤若已烤進像素，先重建遮罩。
- **靜圖**：取 alpha 非零的完整外接框；分離的小物、文字與光點都要算入。少量雜點造成外框異常時，比較遮罩與原圖，再指定修正範圍。等比縮放、置入目標畫布；透明間距、白色描邊、文字可填區是三種不同的設計項目。
- **像素與插畫**：格點圖用最近鄰或依目標重畫小尺寸版，平滑插畫優先測 Lanczos。小圖在 24px／48px 原大及深淺背景查看，確認輪廓和關鍵符號。
- **圖集切割**：規則格依欄列和單格尺寸裁切；不規則格手標 x、y、寬、高。透明連通區可用來找候選框；需將同款分離物件歸回同一格。記下原點與每格毫秒。
- **合成**：背景裝飾、後部件、道具、前部件、文字依遮擋順序在同一透明畫布做 alpha 合成。動作共享底部或特定支點；先求全序列可見範圍的聯集，再以同一比例和原點輸出各格。
- **已有 GIF**：完整解碼每格（含前一格清除與覆蓋），保留時間，排成透明精靈圖並產生 JSON；依 JSON 切回 PNG 格後輸出 APNG。此轉換保留已解碼影像，GIF 先前量化時丟失的顏色或半透明度需回原畫補足。
- **已有生成式工具製作的精靈圖**：檢查實際格線、動作順序、跨格與手勢一致性。以固定框及毫秒描述每格。從零製作時首選高品質透明 PNG 格，分別產出 APNG 與 GIF。
- **時間與容量**：以各格停留時間總和乘以播放次數，計算動畫總時長。停留用延長格時間；匯出後再驗證實際畫格數。先縮小動作區域與刪冗格，再考慮減色；避免改變表意關鍵格。
- **驗收**：淺深底回放、檢查頭尾銜接、半透明邊、最小尺寸辨識、角色或道具的局部漂移。檔案驗證後再進各平台預覽。
- 工具參考：[Pillow PNG／APNG／GIF](https://pillow.readthedocs.io/en/stable/handbook/image-file-formats.html) · [裁切與合成](https://pillow.readthedocs.io/en/stable/reference/Image.html) · [Aseprite 區域切割](https://aseprite.org/docs/slices/) · [OpenCV 連通區](https://docs.opencv.org/4.x/d3/dc0/group__imgproc__shape.html) · [FFmpeg 影片拆幀](https://ffmpeg.org/ffmpeg-formats.html)。
